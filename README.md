This is an Interpreter for the Object Oriented , Dynamically typed programming language called TRAN. 
TRAN is a programming language developed by Prof. Michael Phipps at University At Albany's College of Nanotechnology, Science, and Engineering Department of Computer Science.
This was a semester long project that was given by professor to us during Fall-2024 when I took "CSI 311 -- Principles of Programming Languages" class.
This is a partially functioning Interpreter for TRAN, in reality the Language is much larger with much more complicated cases to take care of. 
But this was an excellent learning opportunity.
